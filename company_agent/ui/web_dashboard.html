公司工作助理

在 Open WebUI 的模型選單選擇「公司工作助理」，輸入需求並附上文件即可。所有已啟用帳號均可使用，模型費用合併扣本人既有每日 US$4 額度。

支援文件、Excel、圖片、本地 OCR、Tavily 公開研究、EIP 附件及 DWG／DXF 結構分析。CAD 不重存 DWG、不覆寫 NAS 原圖；未知圖元、外參與字型可能不完整，不代表整張施工圖已驗證。所需文件內容與選取圖片會送至已設定雲端模型；公開搜尋詞與網頁網址交給 Tavily，請勿提供不允許外送的資料。Tavily 使用管理員設定的 API 額度，與個人模型額度分開。

PNG／JPEG 與 PDF 支援本地 OCR 或指定單頁的雲端圖片語意分析（消耗本人模型額度，不是工程安全認證）。Excel 支援新建計算報表，或核對原值後跨表修改儲存格、受限同表公式及既有樣式，另存不覆寫；原簿修改版需要用 Excel 開啟重算。EIP 可查詢並處理 PDF／DOCX／DOC 附件，同簽核附件共同分析，提供私人 PDF／可編輯 Word／期限 CSV 下載。CSV 旁可預覽，再由本人確認匯入私人行事曆；沒有期限不建立行程。不簽核、不寄信、不刪除，查詢與下載可能更新已讀。
