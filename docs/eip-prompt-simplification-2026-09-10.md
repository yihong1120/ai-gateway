# EIP 提示詞精簡與對照驗證

- `calendar_semantics.py` 的 `EVENT_POLICY` 集中定義待辦成立、日期用途、來源效力、跨附件及缺值規則，產生與核對提示共用，不再分別累積近似規則。
- 移除「申請或提議的日期沒有核准依據就不可當正式安排」的絕對敘述。改為區分待辦本身的既定期限與其所涉及的後續安排是否生效，不以特定詞語決定事件狀態。
- 移除固定 `S1` 與第 1～3 行範例，以欄位型別及實際輸入座標說明來源範圍。
- 保留來源驗證、受限更正、獨立核對、私人設定、去重及 `[AI產生]` 等既有契約。沒有更換模型或修改 EIP 寫入流程。
- 附件組提示詞由 4,325 字元減為 3,930 字元（約 9.1%）；這是字元數，不等於實測 token 或費用減幅。
- 核對提示因共用完整判斷契約，由 743 增為 999 字元；兩段合計由 5,068 減為 4,929（約 2.7%），不能宣稱整條流程省下 9.1% token。

本次依 OpenAI Docs 技能採用明確契約及評測驗證；具體工程名稱、日期及預期答案僅放測試資料，不加入正式提示詞。[官方提示詞指引](https://developers.openai.com/api/docs/guides/prompt-engineering)

## 可重跑測試

離線回歸：

```sh
PYTHONPATH=tests:. python -m unittest discover -s tests -p 'test_eip_*.py'
PYTHONPATH=tests:. python -m unittest test_official_document_processor_pipe
```

實際模型對照測試須在已設定 Open WebUI／資料庫環境中明確啟用；會呼叫部署設定的模型並產生費用：

```sh
EIP_PROMPT_LIVE=1 PYTHONPATH=tests:. python -m unittest test_eip_prompt_live
```

測試以合成文字替代 OCR 輸入，實際呼叫模型並執行正式 LangGraph 判讀、來源驗證、受限更正及核對節點。預期答案不傳給模型；不登入 EIP、不上傳附件、不新增行程、不保存正式處理紀錄。此測試不代表原始 PDF OCR 或正式匯入端到端驗收。
