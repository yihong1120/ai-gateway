# EIP 提示詞與核對流程修正驗收

結論：已修改提示詞與核對流程，但尚未通過完整驗收，不建議據此放寬自動匯入。
本輪未部署、重啟服務、提高額度、切換模型或修改正式行程。沿用 DeepSeek-V4-Flash。

## 程式修改

- 將事件判讀、核對與格式更正提示精簡為通用的事件、執行者、對象、時間、效力及來源關聯規則。
  生產提示詞沒有測試專案名稱、案例日期或預期答案；測試資料與提示詞分離。
- 移除「語意核對否決 → 交回產生模型改寫 → 再讓核對模型批准」的圖路徑。
  語意分歧保留原候選、原文與問題，不執行語意重寫，也不輸出可匯入行程。
  原有一次格式／引用更正仍保留，來源驗證失敗不會當作無事件完成。
- 每筆核對判斷須附 `evidence_spans`，逐段驗證來源 ID、行號、內容與範圍。
  核對引文不參與原文重組，因此不要求列舉順序，也不因範圍交疊而誤擋。
  文件內容重組的原有順序檢查未放寬。
- 核對失敗時保留先前的日期待補等診斷，避免後一道錯誤覆蓋前一道問題。

上述修正防止核對流程引入新的改寫錯誤，但不能保證模型的每個判斷都正確。
「引文存在」也不等於「引文在語意上支持結論」。本輪仍抓到核對模型誤放行。
