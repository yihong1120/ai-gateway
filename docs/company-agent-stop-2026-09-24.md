# Company Agent 聊天停止會取消工作（2026-09-24）

先前 Open WebUI 的停止按鈕只取消 Pipe 輪詢，獨立的佇列工作仍繼續執行。

## 調整

- 沿用 Open WebUI 的 `POST /api/tasks/chat/{chat_id}/stop`。Pipe 收到原生 `CancelledError` 時，取消該使用者此次對應的工作，再繼續傳遞取消訊號。
- 排隊工作標記為 `cancelled`，worker 不再領取；執行中工作取消自身的 asyncio task，沿原本的 LangGraph／模型 client 路徑清理。
- worker 本身持續服務下一筆工作。停止服務則仍取消整個 worker，保留尚未領取的佇列。
- 同一工作被重新產生的訊息共用時，停止會取消這筆共用工作；重複停止不再次打斷清理。
- 聊天進度與工作狀態顯示「已取消」，已有成果仍可下載。已結束的工作不被改寫成取消。

本次沒有新增模型重試、fallback 或自行包裝模型例外。已送達供應商的請求可能仍有費用，已完成的外部操作不會被撤銷；正在執行的同步操作仍受該工具自身的中止能力限制。關閉瀏覽器不等於點擊停止：Open WebUI 已建立的背景聊天 task 仍由其原生生命週期管理。
